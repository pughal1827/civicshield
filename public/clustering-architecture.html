Incident-Fusion Scoring Formula
geoScore = 1 − (distance / 250 m) categoryScore = 1.0 same · 0.60 related pair · 0.10 other semanticScore = cosineSim(embeddingA, embeddingB) or tokenOverlap(textA, textB) if no embeddings combined = 0.45×geo + 0.35×category + 0.20×semantic MATCH if: combined ≥ 0.62 OR: same category AND distance ≤ 180 m Fallback (no embeddings): score capped at 0.60 → no false flags.

■ System Architecture — Component Classification
Component Type Technology Role in Clustering Pipeline
AI Analysis Engine AI Model Gemini 3.6 Flash + Smart NLP fallback Classifies civic category, severity, safety risk (0–100), department. Runs first on every submission.
Embedding Service AI Model Gemini Embedding 001 (3072-d) Dense vector per report. Powers semantic cosine similarity in fusion and duplicate detection.
Incident Fusion Engine ML / Algo Haversine + weighted scoring (deterministic) On submission: finds best active master within 250 m. Clusters new report into it or creates new master.
Duplicate Detector ML / Algo Haversine + cosine + PENDING relations Secondary scan (100 m). Flags potential duplicates as PENDING relations. Human-in-the-loop confirm/reject.
Hotspot Engine Deterministic Density-based spatial clustering (O(n²)) Finds geographic clusters of ≥3 incidents in 500 m radius for officer dashboard. Merges overlapping clusters.
Recurrence Engine Deterministic Same spatial clustering, 180-day window Detects repeat problems at same location. Computes avg days between occurrences and trend direction.
Root-Cause Engine Deterministic Clustering + weighted signal score Groups incidents spatially. Signal score: spatial(35%) + temporal(25%) + category(20%) + recurrence(20%).
Priority Engine Deterministic Weighted scoring formula 5-factor score: Safety Risk(35%) + Severity(25%) + Impact(20%) + Recurrence(10%) + Location(10%).
Escalation Engine Deterministic Rule-based tier classifier EMERGENCY_REVIEW / URGENT / WATCH / NONE based on priority + SLA + recurrence + safety risk.
Officer Dashboard Human React + Next.js (TypeScript) Displays clusters, duplicate flags, root-cause signals, hotspots, recurrence trends. Authority approves merges.
Storage Layer Database Supabase (PostgreSQL + PostGIS) Persists incidents, reports, embeddings, duplicate_relations, audit logs. PostGIS for spatial queries.
